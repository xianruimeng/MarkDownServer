# Welcome to Markdown Editor

This is a **web-based markdown editor** with live preview.

## Features

- Real-time preview as you type
- Syntax highlighting for code blocks
- File management (create, edit, delete)
- Keyboard shortcuts (Ctrl+S to save)

## Code Example

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}
```

## Getting Started

1. Click **+ New File** to create a markdown file
2. Start typing in the editor on the left
3. See the rendered preview on the right
4. Press **Ctrl+S** (or Cmd+S on Mac) to save
